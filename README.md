# Bela Burger — Site oficial

Site institucional da hamburgueria **Bela Burger** (Bela Vista, São Paulo).

## Sobre

- **Endereço:** Rua Conselheiro Carrão, 408 — Bela Vista, São Paulo/SP
- **WhatsApp:** (11) 98265-1852
- **Segmento:** Hamburgueria artesanal
- **Delivery:** sim (confirmar área de entrega pelo WhatsApp)

## Estrutura

- `index.html` — site completo (HTML + CSS + JavaScript em arquivo único, sem dependências de build)
- Imagens ilustrativas carregadas via Unsplash. Substitua pelas fotos reais do restaurante quando disponíveis.

## Publicar no GitHub Pages

1. Vá em **Settings → Pages**
2. Em **Source**, escolha **Deploy from a branch**
3. Selecione a branch `main` e a pasta `/(root)`
4. Salve. O site ficará em: `https://toddyx696.github.io/bela-burger-site/`
